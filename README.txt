To Explain the project, open the file: "HealthMonitorFINAL.py" in any program that runs python code.
The Goal of this program is for astronauts to use this program daily to monitor their physical health, find red flags in their routine, and then act accordingly, either by making chances 
themselves or talking to a medical officer.


The program begins by asking the user for basic information, these are to be filled based on the subject and will change the variables later in the program.
Once these questions are filled, a menu will drop down asking the user to select from the following options:

1. Vision Questionnaire
2. Red Blood Cell Amount
3. Bone Density
4. Blood Lab
5. Muscle Atrophy test
6. Radiation Exposure

Each option chosen has a different list of questions to be answered, in which the user (in some, not ALL) may need the results of tests outside of program to enter in. Once these values are entered, they will be compared to the expected average person, if the entered values fall outside this range, the program will print that it sees this issue, otherwise anything within the expected ranges will not cause any red flags.
The user is now expected to use the program in order to alert a medical officer of their results, and from there the trained professional will decide the best course of action.
